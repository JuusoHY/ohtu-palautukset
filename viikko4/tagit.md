# Git-tagit

Git-tagilla voidaan merkitä ohjelmiston historiasta tärkeä versio.

## Versiomerkinnät

v1.0.0 merkitsee harjoituksen alkutilannetta.
v1.1.0 merkitsee kolmen muutoksen jälkeistä tilannetta.

## Historiaan palaaminen

Komennolla git checkout v1.0.0 voidaan tarkastella vanhaa versiota.
Komennolla git checkout main palataan nykyiseen kehityshaaraan.
